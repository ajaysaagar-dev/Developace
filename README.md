## 📖 Overview

**Developace** provides a streamlined frontend workspace tailored for rapid prototyping, real-time code execution, and component design systems.

---

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
